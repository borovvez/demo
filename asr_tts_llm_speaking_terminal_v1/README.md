Distributed Half-Duplex (Ray + pywebrtc-audio)

**Голосовой терминал v1** — это базовая реализация интеллектуального голосового ассистента, работающая в **полудуплексном режиме** (Half-Duplex) и построенная на распределенной клиент-серверной архитектуре.

### 🛠 Архитектура и Стек
* **Ray Core:** Используется для организации асинхронного взаимодействия. Компоненты ASR, LLM и TTS реализованы в виде удаленных сервисов (Ray Actors) и функций (Ray Tasks).
* **ASR + LLM + TTS:** Изолированные модули обработки речи и генерации текста.
* **Транспорт:** Библиотека `pywebrtc-audio` на стороне клиента для захвата и передачи аудиопотока.

### 🌐 Клиент-серверная модель и Асинхронность
Проект изначально закладывает масштабируемую архитектуру для поддержки множества клиентов:
* **Мультиклиентность:** Серверная часть под управлением <LinkableSpan intent="Изучить концепции Ray Core и работу с асинхронными задачами">Ray</LinkableSpan> эффективно распределяет вычислительные ресурсы кластера между параллельными запросами от разных терминалов.
* **Неблокирующий пайплайн (Ray Futures):** Передача данных между этапами распознавания, генерации и синтеза построена на базе неблокирующих объектов (ObjectRefs / Futures). Это позволяет серверу обрабатывать тяжелые нейросетевые задачи асинхронно, минимизируя задержки (latency) при ответе пользователю.

### 🔄 Принцип работы (Half-Duplex)
1. Клиент записывает голос с помощью `pywebrtc-audio` и отправляет аудиоданные на сервер.
2. Сервер вызывает удаленные задачи Ray, которые асинхронно обрабатывают запрос по цепочке: ASR → LLM → TTS.
3. Сгенерированный аудиоответ возвращается клиенту. Во время воспроизведения микрофон терминала не принимает новые реплики, что гарантирует стабильность и отсутствие эха.
